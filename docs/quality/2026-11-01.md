The ten quality rules checked against the code, with evidence. Go 1.26.10, Terraform 1.17.1,
Windows 11. Nothing here talks to AWS: the Terraform tests use mocked providers and the Go checker
reads `.tf` files, so rules about live services apply only to the Terraform download script and to
what the module would do in a real account.
